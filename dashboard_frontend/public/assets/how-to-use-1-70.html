How to use this kit and Figma?

This Figma Design makes heavy use of powerful Figma features, including components, Auto Layout and Variants.
If you’re new to Figma, be sure to check out Figma’s YouTube channel (https://www.youtube.com/figmadesign) and their Best Practice Guides (https://www.figma.com/best-practices/guides/).

You can insert any component directly into your design via the Assets panel. If you need to make substantial customizations, feel free to detach the instance (Mac: Cmd + Opt + B, Windows: Ctrl + Alt + B) to make the necessary changes.
